# 소리톡 작업 로그 (2026-06 세션)

> 컨텍스트 핸드오프용 요약. 새 세션에서 이 파일만 읽으면 이어서 작업 가능.

## 프로젝트 개요
- **모노레포** (npm workspaces): `apps/*` + `packages/*`
- 배포: `yolkgit/soritok` (public), 서버 `~/soritok` 에서 `./deploy.sh`
- 앱: `hub`(허브/책상), `weekly`(위클리페이퍼+백엔드), `gnugo`(바둑교실), `games`(미니게임), `study`(교육), `mbti`
- 공유 패키지: `@soritok/auth`, `@soritok/ads`, `@soritok/ui`(공통 디자인토큰+BrandHome)
- 단일 오리진 배포: `web`(nginx, 6앱 정적 + `/api` 프록시) + `api`(weekly Express :4000, 호스트 MySQL)

### 2. 미니게임 5종 → 26종 + 사운드
`apps/games/src/games/` 에 각 게임 1파일. `games.ts` 에 등록하면 메뉴 자동 노출.
- **목록**: 2048·스네이크·테트리스·플래피·두더지·벽돌깨기·스택·디노런·기억력·점프·길건너기·버블슈터·블록퍼즐·카드짝맞추기·지뢰찾기·탁구·타이핑·사천성·핀볼·수박게임·미로찾기·슬라이드퍼즐·리듬게임·넘버드롭·다른색찾기·순서누르기
- **움직임 자연스럽게**: 캔버스 게임 dt(프레임률 독립), 스네이크 보간이동, 2048 팝/병합 애니
- **사운드**(`lib/audio.ts`): Web Audio 합성(에셋 0). 효과음(click/point/pop/merge/jump/hit/levelup/win/gameover) + 배경음(펜타토닉 루프) + 게임별 전용 효과음. 🔊/🔇 토글(localStorage 저장)

### 3. ⚠️ 치명 버그 수정 (GameShell)
- **증상**: 점수 오를 때마다 게임이 처음으로 리셋 → 거의 모든 게임 플레이 불가
- **원인**: `handleGameOver` 가 매 렌더 새 함수 → `onGameOver` prop 변경 → 게임 `useEffect([onScore,onGameOver])` 재실행 → 상태 초기화
- **해결**: 콜백을 `useCallback`+`ref` 로 **고정 참조**화. (`GameShell.tsx`)

### 4. 리듬게임 배틀 (핵심)
- **곡 선택 → 난이도 선택(쉬움/보통/어려움) → 플레이** 흐름
- **멀티트랙 곡**(`data/songs.ts`): 멜로디+코드+베이스+드럼 풀편곡을 오디오 클락에 동기 예약. `buildChart(song, diff)` 가 난이도별 차트 생성(멜로디를 정박/8분/전부로 필터)
- **곡·난이도별 순위**: `GameProps.onVariant` 추가 → GameShell 이 `rhythm::곡id:난이도` 키로 기록/리더보드 분리(백엔드 무변경)
- **월간 자동 작곡**: `scripts/composeSongs.mjs`(월 시드 결정론적 절차적 작곡) → `generatedSongs.ts` 출력 → `activeSongs()` 가 최신 month 세트만 반환(title 중복 제외). `.github/workflows/monthly-songs.yml`(매월 1일 자동 생성·커밋). 로컬: `npm run songs:generate`
- **⚠️ 저작권**: 실제 K-POP 멜로디는 임베드 불가 → 오리지널(저작권 free) 곡으로 시드. 실곡은 라이선스 필요

### 5. 바둑교실(gnugo)
- **난이도**: GNU Go 는 최저 레벨도 강함 → 낮은 단일수록 "초보 실수(랜덤 합법수)" 확률 주입(`ai/goWorker.ts`). 1단 85% → 9단 0%
- **광고 가림 수정**: 사이드바 노출 ≥1536px, 하단 배너 여백 확보, gnugo `max-w-7xl`→`max-w-6xl`+`justify-start`

### 6. 배포 최적화 (`Dockerfile.web`, `.dockerignore`, `deploy.sh`)
- **매니페스트 먼저 COPY → npm install(캐시) → 소스 → build**: 코드만 바뀌면 install 스킵
- **앱별 독립 빌드 스테이지**(build-hub/games/...): 바뀐 앱 스테이지만 재빌드 + 병렬
- `BUILDX_NO_DEFAULT_ATTESTATIONS=1`(provenance off)
- 첫 빌드는 풀빌드(~300s), 이후 코드 변경은 해당 앱 스테이지만(~수십 초)

## 운영 메모
- **배포**: 서버에서 `cd ~/soritok && ./deploy.sh` (git pull 포함). `.env` 필요(커밋 금지)
- **"Built 후 멈춤"**: 빌드는 끝났고 이미지 export 마무리 중. `docker compose ps` 로 확인. 컨테이너 안 떴으면 `docker compose up -d` 직접 실행
- **월간 곡 추가**: `data/songs.ts` 의 `ALL_SONGS` 에 추가하거나 Actions 가 자동 생성. 곡은 `melody`+`chords` 만 있으면 자동 편곡
- **보안**: `.env` 절대 커밋 금지(`.env.example` 만). DB 자격증명은 docker-compose `${VAR}`
