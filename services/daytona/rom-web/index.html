    게임 정보
    16:9 확장 시야와 3배 HD 내부 해상도로 고정됩니다. 키보드와 모바일 아날로그 터치 조작을 지원합니다. 모바일에서는 시작 버튼을 누르면 전체화면으로 전환됩니다. 왼쪽 패드로 조향하고 오른쪽 페달을 누르세요. 페달을 누른 채 아래로 내리면 가속·제동 강도가 줄어듭니다. 지원하지 않는 브라우저에서는 페이지 안에서 게임만 확대합니다. W/↑는 즉시 가속, 놓으면 타력 주행, S/↓/R은 주행 중 제동하고 정차 후 약 0.35초 더 누르면 저속 후진합니다. 후진 키를 놓거나 W/↑를 누르면 먼저 멈춘 뒤 전진할 수 있습니다. Space는 후진 없이 제동만 합니다. 이 후진은 웹 버전에서 추가한 기능입니다. 좌우 키는 짧게 누르면 작은 보정, 길게 누르면 큰 회전이 되며, 놓으면 조향 입력이 빠르게 중립으로 돌아옵니다. 코스·자동/수동 선택 화면에서는 좌우 키를 한 번씩 눌러 항목을 바꾸고, 키를 놓아도 선택이 유지됩니다. ↑ 또는 Enter로 결정합니다. 차량 위치를 도로 중앙으로 옮기는 보정은 없습니다.
    FREE PLAY 설정으로 코인 없이 플레이합니다. 온라인 모드는 원작의 기기 간 통신을 WebRTC로 연결해 최대 4명이 함께 달립니다. 직접 연결이 차단된 네트워크에서는 연결되지 않을 수 있습니다.
    제공된 원작 데이터·코드를 바탕으로 만든 WebAssembly·WebGL2 웹 버전입니다. 원본에서 빠진 연산 테이블 2개를 수학 함수로 근사해 완전히 동일한 동작을 보장할 수 없습니다.
