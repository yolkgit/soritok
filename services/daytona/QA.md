# 모바일 조작·후진 검증 (2026-10-31)

- 네이티브 후진: 세 코스, 자동/수동 변속, 정차 진입 지연, 저속 제한,
  실제 위치의 반대 방향 이동, 속도 표시, 키 해제·Space 정지, 전진 복귀 통과.
- 온라인: 원작 기기 4대를 바이트 스트림으로 연결한 상태에서 로컬 물리 차량과
  통신용 차량 복사본의 음수 속도 및 실제 이동 확인. 네 기기 연결 상태 유지.
- 모바일 입력: 패드+두 페달의 독립 접촉, 중간 ADC 강도, 제동 우선,
  터치 취소·포커스 이탈·화면 회전 시 해제, 일시정지 입력 차단 검사 통과.
- 전체화면: 브라우저 API 미지원/거절, 일반 종료, 지연된 API 응답 처리 검사 통과.
- 브라우저: 844×390, 390×844에서 게임 확대와 배치 확인. 가속 페달을 누를 때
  실제 게임 입력 100%, 해제 시 0% 확인. 실물 휴대폰의 멀티터치/OS 방향 잠금은
  현재 PC 브라우저 환경에서 직접 검증하지 못했음.
- 기존 서버 검사: 출석·메모·댓글의 인증/수정/삭제·복원 및 4인 방/시그널링 통과.

## 추가 추적할 원작 실행부 문제

로컬 브라우저 주행 후 세로 화면을 검증하던 중 약 6575 프레임에서 원작 WASM의
`memory access out of bounds`가 한 번 발생했다. 모바일 UI와의 인과관계는 확인되지
않았다. 원본 core와 후진 확장 core를 각각 소리 활성화·3배 GPU 구성으로 8500
프레임씩 실행한 종료/재시작 검사에서는 재현되지 않았다. 해결했다고 간주하지
않으며, 작업자는 다시 발생할 경우 화면의 단계·프레임·스택을 확인해야 한다.
worker의 프레임 루프 오류를 포착하여 입력을 해제하고 재시도 화면을 표시한다.
