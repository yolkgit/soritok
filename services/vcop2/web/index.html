게임 정보 · 조작 안내

제공한 1995년 아케이드판 vcop2.zip의 프로그램·모델·텍스처·음성·판정을 실행합니다. 시작 버튼은 원래의 코인과 START 입력을 보냅니다. 난이도는 원본 화면에서 조준하고 사격하세요.

WebGL2 환경은 실제 3D 시야를 확장한 16:9 · 1920 × 1080으로 그립니다. 원본 HUD와 메뉴 비율을 보존합니다. 성능이 부족하면 720p를 선택하세요. 호환 모드에서는 원본 4:3 화면을 표시합니다.

원본 NVRAM·EEPROM은 이 브라우저에 자동 보관합니다. 진행 중인 스테이지 전체를 저장하는 기능은 없습니다.

터치: 화면을 눌러 조준·사격, 재장전 버튼으로 탄창 보충. 전체화면에서는 왼쪽 아래 ↻ 버튼을 사용하세요. 키보드 Space로 현재 조준 위치에 발사할 수도 있습니다. 화면을 벗어나거나 앱을 전환하면 자동으로 일시정지합니다.
